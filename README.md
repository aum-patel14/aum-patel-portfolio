Aum Patel Portfolio — Premium Data Analyst Portfolio

Built with:
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS v3
- Framer Motion
- GSAP
- Lucide React

Sections:
- Hero (typewriter, floating cards, stats)
- About (glassmorphism info cards, bio, highlights)
- Skills (filter tabs, animated bars)
- Projects (6 analytics projects with expandable details)
- Experience (vertical timeline)
- Certifications (6 industry certs)
- Resume (preview + download)
- Contact (form + social links)

To run locally:
  npm install
  npm run dev

To build for production:
  npm run build
  npm start

To deploy:
  - Vercel: push to GitHub, connect to Vercel
  - Netlify: drag-and-drop the .next/out folder
  - GitHub Pages: use next export

IMPORTANT: Replace public/resume.pdf with your actual resume PDF.
Update personal links in lib/data.ts before deploying.
